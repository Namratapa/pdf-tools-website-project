# PDF Tools Website

A web-based PDF utility application that helps users manage and process PDF documents easily.

## Features

- Merge multiple PDF files into a single PDF.
- Simple and user-friendly interface.
- Upload and process PDF documents.
- Fast PDF processing.

## Technologies Used

- Python
- FastAPI
- PyPDF
- HTML, CSS, JavaScript (if used in your frontend)
